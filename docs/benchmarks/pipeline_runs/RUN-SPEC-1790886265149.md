# Refined Technical Specification: LAN Share (FEAT-012)

## 1. Feature Overview

Feature FEAT-012 introduces a secure, resumable LAN file sharing capability within the Tauri/Rust application. It enables users to share local model directories (e.g., `d:\local-llm-hub\models`) with other devices on the same network via an embedded HTTP streaming server that supports HTTP 206 Partial Content (Range Requests). This allows clients to download large GGUF files (several GB) in chunks, pause and resume downloads, and avoid redundant transfers.

The implementation leverages Rust’s async runtime (`tokio`) and Tauri’s IPC system to provide a robust, cross-platform backend with built-in security safeguards.

## 3. Implementation Details

### 3.1 Backend Commands

#### `start_lan_share`
- **Path**: `commands/share.rs`
- **Signature**:
  ```rust
  pub async fn start_lan_share(
      ctx: &Ctx,
      share_path: String,
      port: u16,
      read_only: bool,
      pin: Option<String>,
  ) -> Result<LanShareStatus, Box<dyn std::error::Error>>
  ```
- **Behavior**:
  - Validates that `share_path` is a valid directory and exists.
  - Binds a TCP listener to `0.0.0.0:port`.
  - Starts a background task using `tokio::spawn` to serve files.
  - Returns `LanShareStatus` with `is_running: true`, `local_ip`, `port`, `file_count`, and `total_size`.

#### `stop_lan_share`
- **Path**: `commands/share.rs`
- **Signature**:
  ```rust
  pub async fn stop_lan_share(&ctx: &Ctx) -> Result<LanShareStatus, Box<dyn std::error::Error>>
  ```
- **Behavior**:
  - Stops the background server task.
  - Releases the port.
  - Returns `LanShareStatus` with `is_running: false`.

---

### 3.2 HTTP Server & Range Request Handling

- **Server**: Built using `axum` with `tokio::fs::File` for streaming.
- **Range Support**: Parses `Range: bytes=start-end` header and returns `HTTP 206 Partial Content`.
- **Path Validation**:
  - All file paths are validated to prevent directory traversal (`..`).
  - Absolute paths outside `share_path` are rejected.
  - Example: `/models/mellum2-12b.gguf` is allowed; `/../etc/passwd` is blocked.

## 6. Performance Optimization

- **Buffered Streaming**: Uses `tokio::fs::File` with a bounded buffer (1MB) to prevent OOM on 16GB systems.
- **Concurrent Requests**: Handles multiple simultaneous download requests efficiently using `axum`'s async routing.
- **Minimal Memory Footprint**: Stream processing ensures low memory usage regardless of file size.
