## Architectural Decision Record (ADR-100)

**Decision:** Use `Result<T, String>` for error propagation in CSV parsing
**Rationale:** Aligns with STD-003 guard rails - never use unwrap/expect/panic. String errors are appropriate for CSV parsing failures.

---

## Implementation

```rust
// trace:implements FR-006
#[derive(Debug, PartialEq)]
pub struct GpuStats {
    pub name: String,
    pub vram_used_mb: u64,
    pub vram_total_mb: u64,
    pub temp_c: u32,
    pub util_pct: u32,
}

// trace:implements FR-006
pub fn parse_gpu_csv(line: &str) -> Result<GpuStats, String> {
    // Guard: line must not be empty
    if line.is_empty() {
        return Err("Empty CSV line".to_string());
    }

    // Split by comma delimiter
    let parts: Vec<&str> = line.split(',').collect();

    // Guard: exactly 5 columns required
    if parts.len() != 5 {
        return Err(format!("Expected 5 columns, found {}", parts.len()));
    }

    // Parse each field with error handling
    let name = parts[0].trim().to_string();
    let vram_used_mb = parts[1].trim()
        .parse::<u64>()
        .map_err(|e| format!("Failed to parse vram_used_mb: {}", e))?;

    let vram_total_mb = parts[2].trim()
        .parse::<u64>()
        .map_err(|e| format!("Failed to parse vram_total_mb: {}", e))?;

    let temp_c = parts[3].trim()
        .parse::<u32>()
        .map_err(|e| format!("Failed to parse temp_c: {}", e))?;

    let util_pct = parts[4].trim()
        .parse::<u32>()
        .map_err(|e| format!("Failed to parse util_pct: {}", e))?;

    Ok(GpuStats {
        name,
        vram_used_mb,
        vram_total_mb,
        temp_c,
        util_pct,
    })
}
```

## Verification

| Test Case | Input | Expected Result |
|-----------|-------|-----------------|
| Valid CSV | `"NVIDIA GeForce RTX 3060, 5800, 12288, 35, 25"` | `Ok(GpuStats { name: "NVIDIA GeForce RTX 3060", vram_used_mb: 5800, vram_total_mb: 12288, temp_c: 35, util_pct: 25 })` |
| Too few columns | `"GPU, 5800"` | `Err("Expected 5 columns, found 2")` |
| Too many columns | `"GPU, 5800, 12288, 35, 25, extra"` | `Err("Expected 5 columns, found 6")` |
| Invalid number | `"GPU, abc, 12288, 35, 25"` | `Err("Failed to parse vram_used_mb: invalid digit found in string")` |
| Empty line | `""` | `Err("Empty CSV line")` |

**No unwrap/expect/panic used** - all error paths return `Err(String)`.
